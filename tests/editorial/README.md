# 选材与文案回归

`synthetic-contexts.json` 含 12 位虚拟用户的合成材料，其中 9 份覆盖九种主题，另 3 份测试只有摘要、素材平淡和容易误读的情况。每次只把一个 ID 的上下文和待测口令发给独立会话。把返回的备用码整理成一个 JSON 对象，键为匿名 ID，值为完整单行报告码。

从仓库根目录运行：

```sh
node tests/editorial/audit.mjs /path/to/codes.json
node --test tests/editorial/audit.test.mjs
```

`review-key.json` 只给验收者。自动检查复用出图页的解析器，核对主题、每日与总发言数、引语逐字出处及日期。材料未标注逐条命中，因此各日主题命中需要人工复核。

试读时逐份随机交换新旧报告的左右顺序，隐藏版本标记。让评审选想发给朋友的那份，允许平手或两份都不选，并摘出自己记住的那句话。最后用判分依据中的 `actions` 和 `avoid` 对照事实、被引者及跨回合因果。所有对话和人物仅作测试使用。

## 文字客户端到图片

`portable-replies.json` 保留了 Codex 和 Gemini 官方网页访客会话对合成材料的实际答复，包含 Gemini 额外附上最后一句 AI 回答的例子。用例覆盖只有一段可核原话、只有记忆摘要与有完整日期账的双方对话。以下测试将回复原文连同围栏、操作说明和固定网址一起交给出图页，核对原话先后、缺失统计和下载的 PNG。

```sh
python3 -m unittest discover -s tests -p test_portable_images.py -v
```

需要 Python Playwright 及其 Chromium、WebKit、Firefox 浏览器。移动设备配置检查浏览器渲染；ChatGPT 等原生 App 的验收还需在该 App 内实际发送口令、复制回复并保存图片。拒绝剪贴板权限、旧空链接和刷新恢复另见 `tests/clipboard-handoff.test.mjs`。

## 有记忆、没有完整目录的账号

`recall-fixtures.json` 是五个虚构账号的独立盲测材料。每轮开一个空会话，只给它相同的生成口令、待测版本的 SKILL.md 和该账号的 `current` 线程编号。评审保管整份夹具。宿主通过以下只读操作提供材料。

- `memory()` 返回该账号的 `memory` 摘要。
- `search(query)` 对标题和消息做不区分大小写的连续文字查找，返回命中线程的编号、标题和日期。
- `open(thread)` 返回对应线程的原文及发送日期。数组的三项依次是月日、标题和发言列表，`u:` 代表用户，`a:` 代表助手。

带有 `directory` 的账号额外提供可翻页目录，每页两条。归档线程只可通过搜索找到；搜索按日期降序最多返回三条。给两版都提供按需读取选材参考的途径。

每个版本分别运行，记录实际打开的编号和最终入选的逐字原话。给评审看的两版图遮住版本号。原话能否让人记住、是否有个人语气，由评审判断。以下各项可直接从材料核验：

| 账号 | 核验事项 |
| --- | --- |
| mixed | 首屏只有论文问题。检查是否找到生活场景。比较花生壳、奶油的两笔账和普通论文提问。朋友投稿的句子不能署给本人。 |
| quiet | 检查是否找回旧台历或车票。善意也可以很有个人气味。圈画歪、保留铅笔印均有本人原文；亲历的细节不能靠回忆摘要补写。 |
| single | 只有一段原文。观察有没有读到试播后的结果、猫找了半宿。保留单场范围与同日记录。 |
| memory_only | 找不到原线程时，凭杯盖盲测这个具体动作生成短卡。核对零条逐字引语，日期、次数均未知。 |
| archive | 翻完三页目录只能见到六次普通排版。记忆中的「夜光贴」能找回较早的眼镜盒原文；本人当时改称「绿点」，沿用这个称呼能再找到半夜拎回猫粮的下文。核对日期与说话人。两个日期属于一件事。年度类型需要另一件独立事情支撑。只读图上文案，要能说出猫为什么来开饭：用户摸着绿点，拎回的是猫粮。可用本人原话，也可写进核实的事实前情。 |

前两组刻意不给原文目录。把所有线程同时贴给模型只能检验选句，无法检验它是否会从记忆主动找回原文。
