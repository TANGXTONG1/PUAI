# 怎么从一年的聊天里选现场

1. **先翻记录。** 从宿主已经允许读取的对话目录或历史搜索进入原线程。按技能正文盘点可读范围，打开早期、发言密集期和近期多个不同时段的原文，用「上回」「我自己」「你倒是」这类本人用词或反复出现的物件再找一轮。近期全是找文件、问下载时，也要打开其他时段的原文再定主题。
2. **把候选抄回来。** 私下为每个候选记下日期、线程、说话人和本人逐字原句，再看它接的是哪句、后来有没有可核结果。用户消息里引朋友的话或托 AI 改稿时，圈出实际作者。AI 的提议、承诺和用户后来亲自做过的事各记各的。只有摘句就选能独立读懂的那句，只有摘要就保留一件可核的事。
3. **先挑一句能当封面的。** 把几条原话单独读给一个没见过这段聊天的人听。具体到一种食物、一笔价钱或一句别扭的客气，往往能让人立刻听见说话人的口气。术语多、讲得长、出现得勤，都不足以让一句排在前面。有人一本正经地问一件荒唐小事，就让原句自己响起来。两句同样成立，优先挑有具体对象的 PUAI 吐槽。若翻到的全是工作纠错或文件回执，再去有记录的其他时期找生活小事。
4. **给第二句留个落点。** 私下试排两种两句组合，选朋友能一下讲明白的一组。可以是同一种较真用在两件不相干的小事上，也可以是当时还在客气，几天后把欠账翻了出来。前后真的接得上时保留顺序，跨天标各自日期。只有一句站得住，直接用它。一期通常两句；第三句得带来意料之外的结果，删掉后若读起来一样好，就删掉。编辑完成才把选择写进 JSON、报告单或预览链接，所有路径共用这份选择。统计仍根据已核的全批消息。
5. **再看还有什么要印。** 优先让第一条原话出现在第一屏。日期、对象、顺序已经清楚，就省去「先……再……」式总结及替读者解读笑点的旁白。标签可从当事人的词里长出来；换个人仍能原封不动贴上的词就留空。可核范围只有一个线程时用「本次对话精选」，只有零散原话时用「聊天片段精选」。

### 三种剪法（虚拟测试材料）

- **留下什么。** 助手把搁板方向画反，用户要留下涂蓝的螺丝孔。几天后用户自述，上一张就是照着那两个点装的。把两个日期分开，让第二次的实物结果收尾。「用户会鼓励 AI」拿不出这两个点。
- **同一个东西换了什么工作。** 酸奶盖先给葱记日期，后来有人提议把它挂在调料袋上，用户嫌响，最后把三只盖挂到门口催还饭盒。写出哪份差事没接，读者才看得见这个人的取舍。提议、做成和用过各保留原来的状态。
- **当时多管的一件闲事。** 离关店还剩十分钟，用户还想给没报名的人留位置。等表拿回来，最下面那两行真的被填了。选出这句后来才到的回音，分别标出两天的日期。
