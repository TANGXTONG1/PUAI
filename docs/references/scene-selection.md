# 怎么从一年的聊天里选现场

1. **先翻记录。** 从宿主已经允许读取的对话目录或历史搜索进入原线程。记录横跨几个月时，先翻早期、发言密集期和近期各一处，用「上回」「我自己」「你倒是」这类本人用词或反复出现的物件再找一轮。近期全是找文件、问下载时，也要打开其他时段的原文再定主题。
2. **把候选抄回来。** 私下为每个候选记下日期、线程、说话人和本人逐字原句，再看它接的是哪句、后来有没有可核结果。用户消息里引朋友的话或托 AI 改稿时，圈出实际作者。AI 的提议、承诺和用户后来亲自做过的事各记各的。只有摘句就选能独立读懂的那句，只有摘要就保留一件可核的事。
3. **用原话选原话。** 遮住人格分析，让最近的一句跟另外两个现场的本人原声比一比，有多少材料就比多少。优先选朋友会照念的原句，比如出人意料的比喻、带刺的客气、跨月重提的一笔账，或准确到某个小细节的夸奖。同样有记忆点、有证据时优先 PUAI。「按钮在哪儿」这类问句可以证明当时遇到了问题。找到更有个人口气的原句时，选后者。
4. **把解释剪掉。** 先只排入选原句及能核准的日期。若差半步才能懂，补一句具体前情或那句真实的 AI 回答。不同线程的两句按各自日期展示。页面上若几栏都在说“用户会验收”，把重复的导语、场景复述和结尾评语删掉。只找到一个好现场，一句也能出图。单次行为撑不起年度人格时留空。

### 三种剪法（虚拟测试材料）

- **留下什么。** 助手把搁板方向画反，用户要留下涂蓝的螺丝孔。几天后用户自述，上一张就是照着那两个点装的。把两个日期分开，让第二次的实物结果收尾。「用户会鼓励 AI」拿不出这两个点。
- **同一个东西换了什么工作。** 酸奶盖先给葱记日期，后来有人提议把它挂在调料袋上，用户嫌响，最后把三只盖挂到门口催还饭盒。写出哪份差事没接，读者才看得见这个人的取舍。提议、做成和用过各保留原来的状态。
- **当时多管的一件闲事。** 离关店还剩十分钟，用户还想给没报名的人留位置。等表拿回来，最下面那两行真的被填了。选出这句后来才到的回音，分别标出两天的日期。
